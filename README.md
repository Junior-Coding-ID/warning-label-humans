One-line safety warning label that should come printed on every human being — for the [Warning Label for Humans: One Line, Big Laugh](https://make.fun/bounty/u-0xb3e689-warning-label-for-humans-one-line-big-laugh-40e31f85) bounty on make.fun.

## Entry

> WARNING: Do not tell a human to act natural for a photo. Unit may forget where its arms go.

91 characters — inside the 160-character gate.

## How it works

`main.ts` writes the entry text to `/output/entry.txt` (creating `/output` first). Run it with Node 22+:

```sh
node main.ts
```
